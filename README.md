# OpenMyau Revamp

An updated build of the OpenMyau client with extra modules added.

## Added modules
- Clutch
- AutoBedDef
- FastBow
- HitParticleEffects
- MoveFix
- ItemPhysics
- BlockOverlay
- BackTrack
- Capes
- SprintReset

## Installation
1. Download the latest `.jar` from the Releases page.
2. Put it in your Minecraft mods folder.
3. Use Minecraft version 1.8.9 forge
